# myrczek.com

Pliki strony **https://myrczek.com** (Wojciech Myrczek, wokalista jazzowy). Hosting: GitHub Pages.

- `/` — strona polska (`index.html`), `/en/` — angielska
- `style.css`, `script.js` — wspólny wygląd i skrypty (zmieniając je, podbij `?v=` w obu plikach HTML)
- `img/` — zdjęcia i favicona
- `m/` — stare adresy: `qrlanding.html` (kod QR z pocztówek — adres nie może się zmienić), `listen.html`, `single/`, oraz przekierowania `myrczek.html` → `/`, `myrczek_en.html` → `/en/`
- `CNAME` — domena dla GitHub Pages (nie usuwać)
- `.github/workflows/` — strażnik dostępności (co godzinę) i przegląd linków (co poniedziałek)

Repozytorium jest publiczne: tylko pliki strony, żadnych haseł, umów, stawek ani danych prywatnych.
